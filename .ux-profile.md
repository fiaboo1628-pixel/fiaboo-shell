# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Custom (Windows 11 Fluent)
- **Notes:** Desktop shell for Hyprland. Taskbar at the bottom, Start and pinned apps centered, tray/clock/notifications on the right. Radius 8, 1px borders. Every surface: `PANEL_FILL` (80 %) over Hyprland blur, no glass (plugin removed 2026-11-01). Colors: one palette from `theme` (`palette()` in src/main.rs reads palette.conf, Catppuccin Mocha fallback), dark only; nothing follows the wallpaper. One font: JetBrainsMono Nerd Font, scale 12/14/16, max weight semibold. Motion soft and slow (easeOutQuint); never snappy.

## Banned anti-aesthetics

- Blur without a visible 1px border and enough text contrast (exception: the terminal, borderless at the owner's choice on 2026-11-01; focus shows by its opacity)
- Decorative gradients and neon/glowing borders
- Floating pastel pill badges for ordinary metadata
- Rainbow or multi-color gradients on buttons
- Cartoon empty-state illustrations
- Emoji as UI icons; mixing icon sets
- Fast/snappy easing

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** Text ≥ 4.5:1 on the 80 % fill over blur, borders/large text ≥ 3:1
- **Pointer / focus:** Used at the desk with mouse and keyboard (remote GUI use such as VNC is rare, do not design for it): comfortable mouse targets (~32–40px hit area); visible focus on keyboard navigation

## Brand tone and microcopy voice

- **Voice:** Utilitarian & Minimal
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** English everywhere (shell and ctrl-menu). Short Windows-style labels: "Shut down", "Restart", "Wi-Fi off".

## Icon library

- **Library:** Project font + theme icons
- **Package / path:** JetBrainsMono Nerd Font glyphs for UI controls; kora icon theme (`~/.local/share/icons/kora`) for app icons
- **Notes:** Do not add another icon set.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon sources. Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
